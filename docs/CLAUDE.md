# Vidisha Infotech Project Guide

## Architecture

React frontend → Laravel API → MySQL

## Backend

Laravel is responsible for API endpoints, business logic, validation, authentication, authorization, and database operations.

## Frontend

React is responsible for the application interface and communicates with Laravel through HTTP APIs.

## Database

MySQL is accessed through Laravel.

React must not connect directly to MySQL.

## Development Rule

Follow the project phase structure.

Do not implement features from later phases before their planned phase.

Keep documentation synchronized with project changes.
